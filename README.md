# CrewHub

> 목표 기반 모임을 위한 실시간 협업 및 지식 아카이빙 플랫폼

## 📖 프로젝트 소개

CrewHub는 공통의 목표를 가진 사람들이 모임을 생성하고 참여하며, 실시간 채팅과 문서 아카이빙을 통해 지식을 축적할 수 있는 플랫폼입니다.

기존 메신저 기반 모임 서비스는 실시간 소통에는 강점이 있지만 정보 관리가 어렵고, 커뮤니티 서비스는 기록 관리에는 강점이 있지만 실시간 소통이 어렵다는 문제를 해결하고자 기획되었습니다.

CrewHub는 **모집 → 참여 → 활동 → 아카이빙** 의 흐름을 하나의 서비스에서 제공합니다.

## 🏗️ 시스템 아키텍처

```text
React + TypeScript (VibeX)
        │
        ▼
Spring Boot REST API (Render)
        │
        ├── Spring Security + JWT
        ├── Spring Data JPA
        ├── WebSocket + STOMP
        │
        ▼
    PostgreSQL (Render)
```
